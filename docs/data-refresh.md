# 令和8年度予算CSVの更新手順

## 現在のデータ経路

東京都オープンデータカタログの「TOKYO予算見える化ボード データ一覧」に登録された8種類のCSVを参照する。リソースURLのパスには `R6` が含まれるが、各CSVには令和8年度（2026年度）の行が追加されている。

画面の基準額はソースコードから直接このJSONを読み込む構成ではない。そのため、正規化後に検証処理を実行し、9分野の名称・金額・合計と一般会計歳出総額が実装値に一致することを確認する。

## 再実行

```sh
npm run data:fetch
npm run data:normalize
npm run data:validate
```

- `data:fetch`：8種類の公式CSVを `data/tokyo-budget/fy2026/raw/` に保存し、URL・取得日時・応答情報を記録する。
- `data:normalize`：Shift_JISをUTF-8へ変換し、列名、年度、金額単位を統一したJSONを生成する。
- `data:validate`：8リソース、2026年度、9分野、一般会計総額96,530億円、実装中の分野名・基準額との一致を検証する。

## 人が確認する項目

1. [令和8年度予算概要](https://www.zaimu.metro.tokyo.lg.jp/zaisei/yosan/r8/8yosangaiyounituite)の一般会計総額が96,530億円である。
2. 目的別9分野の表示順・名称・金額が予算概要および正規化JSONと一致する。
3. CSVの列追加や名称変更があった場合、値を推測で補わず、正規化・検証処理を更新する。
4. 取得日時と差分を確認してから生成データをコミットする。
