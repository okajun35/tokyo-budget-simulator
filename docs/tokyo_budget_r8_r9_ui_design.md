# 東京予算ラボ
## 令和8年度「現在の予算」と令和9年度「次の方向」を分離するUI案

作成日: 2026-08-11

---

# 1. 結論

画面上では、次の3つを分離する。

1. **令和8年度当初予算**
   - シミュレーターの基準値
   - 「現在、東京都はこの分野で何をしているのか」を説明する材料

2. **ユーザーの選択**
   - 増やす
   - そのまま
   - 減らす

3. **令和9年度に向けた東京都の方向**
   - ユーザーの選択に関係なく、独立して常に表示する
   - 「東京都自身は次に何を考えているのか」を示す
   - 令和9年度予算額そのものではなく、予算見積方針・2050東京戦略の2027年度計画を表示する

この構成を推奨する。

```text
令和8年度
いま東京都は何をしている？
        ↓
あなたなら
増やす / そのまま / 減らす
        ↓
選択に応じた説明
        ↓
令和9年度に向けて
東京都は何を考えている？
        ↓
あなたの予算案と東京都の方向を並べて見る
```

---

# 2. 令和8年度予算の扱い

## 2.1 シミュレーターの基準値は「令和8年度当初予算」

令和8年度東京都一般会計当初予算は、

**9兆6,530億円**

である。

令和8年第1回東京都議会定例会で、令和8年度東京都一般会計予算は**原案可決**されている。

したがって、現在のシミュレーターの9分類を、

> 令和8年度当初予算

として使うことに問題はない。

---

## 2.2 ただし、年度途中で補正予算が成立している

2026年6月24日、東京都議会は

> 令和8年度東京都一般会計補正予算（第1号）

を原案可決した。

補正額は **542億円**。

主な目的は、

- エネルギー価格・原材料高騰への対応
- 中小企業等への支援
- 医療・介護・福祉施設等への物価高騰対策
- 脱石油依存
- 省エネ・再エネ
- 資源循環
- 脱炭素化

など。

したがって画面上では、

```text
令和8年度当初予算
9兆6,530億円
```

をゲームの固定基準とし、

必要なら別に、

```text
最新の予算アップデート
2026年6月：542億円の補正予算が成立
```

と表示する。

### 推奨

MVPでは、補正予算を9分類のスライダー初期値へ再配分しない。

理由は、当初予算の9分類と、補正予算の事業別金額を再集計すると、
データ加工と説明責任が増えるからである。

**ゲームの基準は当初予算、最新動向は補足情報**と分離する。

# 4. 「そのまま」を選んだ場合に見せる内容

これまで、

> 金額据え置きと実質的なサービス変化を安全に対応付けられる代表事例は現在未収録です。

としていた部分は削除する。

代わりに、

> **令和8年度、この予算で東京都が進めている主な取組**

を表示する。

重要なのは、ここで表示する事業例を

> 「この分類の予算総額の内訳」

とは表現しないことである。

目的別分類と局別・事業別予算は完全な1対1ではないため、

> **この分野に関係する令和8年度の主な取組例**

とする。

> **この予算の性質**
>
> 公債費は、過去に発行した都債の元利償還などに関係する経費です。

# 6. 増やす・そのまま・減らすで表示を変える

## 増やす

現在のシミュレーターの説明を使用する。

```text
あなたの選択
教育と文化　＋800億円

増やした場合に考えられること
・支援対象を広げる
・設備更新を前倒しする
・新しい施策を追加する

※実際の効果は配分先や制度設計によって変わります。
```

その後に令和9年度の独立カードを表示。

---

## そのまま

「変化なし」だけで終わらせない。

```text
あなたの選択
教育と文化　そのまま

令和8年度、この予算で進めていること
・公立学校普通教室空調更新
・都立高校海外留学支援
・授業料負担軽減
・文化発信

同じ予算額でも、物価や対象者数、
事業内容によってサービス内容は変わることがあります。
```

その後に令和9年度の独立カードを表示。

---

## 減らす

現在のシミュレーターの説明を使用する。

```text
あなたの選択
教育と文化　－800億円

減らした場合に考える必要があること
・対象事業を絞る
・更新時期を遅らせる
・別の財源を探す

※どのサービスが減るかは、実際の政策判断によります。
```

その後に令和9年度の独立カードを表示。

# 7. 令和9年度は必ず独立項目にする

令和9年度については、

- 増やす
- そのまま
- 減らす

のどの選択でも**同じ位置に必ず表示**する。

名称は、

> **令和9年度に向けた東京都の方向**

がよい。

「東京都の令和9年度予算」ではない。

現時点では予算案が確定していないためである。

# 9. 最終画面でやるとよいこと

ここが今回の変更の価値が最も出る部分。

ユーザーの配分結果だけで終わらせず、

> **あなたの選択と、東京都が次に考えていること**

を並べる。

例：

| 分野 | あなたの判断 | 東京都の令和9年度に向けた方向 |
|---|---|---|
| 福祉と保健 | ＋500億円 | 高齢者・医療・生活支援を強化 |
| 教育と文化 | そのまま | 教育充実・文化発信を継続 |
| 労働と経済 | ＋200億円 | 中小企業・スタートアップ・AX |
| 生活環境 | －300億円 | 脱炭素・エネルギー転換を加速 |
| 都市の整備 | －200億円 | 都市強靱化・交通を推進 |
| 警察と消防 | そのまま | 治安・サイバー・災害対応を強化 |
| 企画・総務 | そのまま | AI・データ・行政改革を推進 |

これによって、

```text
私は環境予算を減らした
        ↓
一方、東京都は脱炭素・エネルギー転換を
次年度の重点として考えている
        ↓
なぜ違うのだろう？
```

という思考につなげられる。

# 10. 「東京都との一致度」は出さない

これは重要。

例えばユーザーが、

> 生活環境を－10%

とした一方、東京都が

> 脱炭素を推進

としていても、

**東京都が生活環境予算を増額する予定だという意味ではない。**

令和9年度予算額はまだ確定していない。

したがって、

```text
東京都との一致度 40%
```

や

```text
あなたは東京都と反対です
```

のような評価はしない。

表示するのはあくまで、

```text
あなたの予算判断
VS
東京都が示している政策方向
```

まで。

ユーザーに比較と判断を委ねる。

```text
+
令和9年度に向けた東京都の方向
```

## 最後


# 17. この変更によってゲームの意味が変わる

変更前：

```text
東京都の予算を増減する
↓
結果を見る
```

変更後：

```text
東京都はいま何をしているか知る
↓
自分ならどう配分するか決める
↓
東京都が次に何を考えているか知る
↓
自分の判断と比べる
↓
必要なら東京都へ意見を届ける
```

単なる「予算配分ゲーム」から、

> **東京都の現在を知り、自分で考え、東京都の次の方向と比較する政策理解ツール**

に寄せられる。

この方が都知事杯の

> 国や自治体の政策や財政を分かりやすく可視化

というテーマとの整合も高い。

# 19. 最終提案

**採用する構造**

```text
令和8年度当初予算
= 現在の基準

ユーザーの増減判断
= 自分ならどうするか

令和9年度に向けた東京都の方向
= 東京都自身は次に何を考えているか
```

この3つを混ぜない。

特に令和9年度を増減結果の「説明材料」にしないこと。

令和9年度方針は、

> **東京都からユーザーへの答え合わせではなく、比較材料**

として独立させる。

これにより、ユーザーが予算を増やしても、減らしても、そのままにしても、
最後に「東京都は今後どこへ向かおうとしているか」を知ることができる。
