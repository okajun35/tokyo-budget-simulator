# 2分デモ構成

## このデモで一番伝えること

> 東京予算ラボは、予算の正解を出すサービスではない。限られた総額の中で優先順位を選ぶ難しさを体験し、数字の意味、予算が決まる過程、現実の参加先までつなぐサービスである。

年間総予算を変えずに、公債費から教育と文化へ840億円を再配分する一つの物語に絞る。画面を順番に紹介する「機能ツアー」にはせず、利用者の選択から疑問が生まれ、その疑問に画面が答えていく構成にする。

デモ後に覚えてほしいことは三つだけである。

1. 何かを増やすには、何かを減らす必要がある。
2. 予算項目は、スライダーで動かせても現実には単純に削れない。
3. 自分の関心を、予算成立過程の理解と公式の参加先へつなげられる。

## この題材を選ぶ理由

- 教育は「増やしたい」と直感的に考えやすく、再配分の目的を短時間で共有できる。
- 公債費は名称だけでは意味が分かりにくく、金額を動かしたあとに「そもそも何のお金か」という自然な疑問が生まれる。
- 公債費を減らしても、既に発行した都債の返済義務が消えるわけではない。この説明により、シミュレーターが正解を自動生成するものではないことを示せる。
- 840億円という同じ金額が、公債費の減額、配分可能額、教育の増額として移動するため、固定総額の仕組みを視覚的に追いやすい。

ここでいう「公債費」は、過去に発行した都債の元金・利子を返す歳出である。「都債」は新たな借入やその残高であり、同じものではない。質疑で混同された場合は `/fiscal-context#bond` を使って説明する。

## 2分間の進行と話す内容

### 0:00–0:15｜問いと基準を示す

- トップで令和8年度、一般会計総額9兆6,530億円を示す。
- 年間総予算と配分済みがともに96,530億円、配分可能額が0億円であることを示す。
- 「教育を増やしたいとき、限られた予算のどこから移すかを考えます」と一つの問いを置く。

この段階では制度説明を始めない。まず、実在する年度と固定総額を使った仮想シミュレーションであることだけを共有する。

### 0:15–0:35｜減らす選択をする

- 公債費を2,799億円から1,959億円へ動かす。
- `-840億円`、`-30.0%`、配分可能額840億円を指して確認する。
- 「減らした分だけ、別の分野へ配れるお金が生まれました」と説明する。

操作自体より、減額が即座に配分可能額へ変わることを見せる。基準額の70%は「30%減」であり、「70%減」ではない。

### 0:35–0:50｜別の優先分野へ移す

- 教育と文化を15,922億円から16,762億円へ動かす。
- 配分可能額が0億円へ戻り、年間総予算が96,530億円のままであることを示す。
- 「教育を増やせましたが、その代わりに公債費を減らしています」とトレードオフを言葉にする。

ここがデモの中心である。スライダーの便利さではなく、Aを減らした分だけBを増やせるという価値判断を見せる。

### 0:50–1:20｜選んだ数字の意味を確かめる

- 公債費を選び直して「詳しく見る」へ進む。
- 公債費が元金返済・利子支払いなどの経費であることを示す。
- 返済義務が消えるわけではなく、返済時期、別財源、新規都債、条件変更など複数の論点があることを示す。
- 「画面では減らせても、現実に何を変えるかは一つに決まりません」と説明する。

この30秒で、単純な人気投票型シミュレーターとの違いを伝える。具体的な変更方法は確定案ではなく検討例である。

### 1:20–1:35｜事例と限界を示す

- 詳細末尾の「実際の事例を見る」を開く。
- 夕張市とプエルトリコの公的事例があることを示す。
- 「他地域で確認された事実で、東京都の結果予測ではありません」という注意を必ず添える。

事例の細部を読み上げない。公的資料へ遡れることと、事例を予測として扱わない設計だけを示す。

### 1:35–1:50｜予算が決まる過程へつなぐ

- 共通メニューの「予算が決まるまで」を開く。
- 各局要求、財務局査定、知事査定、予算案、都議会審議、議決・成立の順を示す。
- 「実際の予算はスライダーだけで決まらず、複数の判断段階を経ます」と説明する。

要求額、査定額、予算案、成立予算を混同しないことが、この画面を見せる目的である。

### 1:50–2:00｜現実の参加先で終える

- 公債費の主な所管である財務局を示す。
- 都民の声、請願・陳情などの公式案内へ移動できることを示す。
- 「意見の反映は保証されませんが、考えて終わりではなく、公式の制度を知るところまでつなぎます」と締める。

最後をデータや技術説明ではなく参加先にすることで、このサービスの目的が財政理解だけでなく都政参加支援にもあることを残す。

## 基金・都債・都税の扱い

基金・都債・都税は重要だが、通常の2分デモ本編には入れない。これらを操作すると、歳出9分野の再配分だけでなく、収入、借入、将来返済、年度間の残高まで説明する必要があり、中心メッセージがぼやけるためである。

ただし、次の質問が出たときは、トップの3カードまたは `/fiscal-context` を20〜40秒の補足として使う。

- 「なぜ総予算を増やせないのか」
- 「基金を取り崩せばよいのではないか」
- 「都債を増やせば教育も増やせるのではないか」
- 「動かせないとは、本当に変更できないという意味か」

補足では、「実際には変更されるが、今回は固定総額の歳出配分へ焦点を絞るため操作対象外」と説明する。詳細な財政シミュレーションを実装済みであるかのようには話さない。

## 2分では見せないもの

- 9分野すべての説明
- 全変更方法と全事例の読み上げ
- 出典ページの全メタデータ
- 基金・都債・都税の詳細説明
- CSV取得・正規化処理の技術説明
- すべての参加制度の比較

これらは不足ではなく、質疑や自由操作で掘り下げる情報である。2分本編では、一つの再配分を最後まで途切れず追えることを優先する。

## デモ前の準備

1. `npm run dev` でローカル起動する。
2. トップを開き、「初期値に戻す」で配分可能額を0億円にする。
3. 公債費・教育と文化の詳細導線、予算成立過程、参加ページが開けることを確認する。
4. ブラウザの拡大率を100%にし、通知や別タブを閉じる。
5. 説明が長くなった場合は事例の細部を削り、固定総額の再配分と参加先の締めを残す。
