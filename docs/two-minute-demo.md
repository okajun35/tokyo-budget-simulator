# 2分デモ手順

## 目的

年間総予算を変えずに、公債費から教育と文化へ840億円を再配分し、数字の意味、他地域の事例、予算成立過程、現実の参加先まで一続きで確認する。

## 操作

1. **0:00–0:15｜基準を確認**
   - トップで令和8年度、一般会計総額9兆6,530億円を確認する。
   - 年間総予算と配分済みがともに96,530億円、配分可能額が0億円であることを示す。
2. **0:15–0:35｜公債費を減らす**
   - 公債費を2,799億円から1,959億円へ動かす。
   - `-840億円`、`-30.0%`、配分可能額840億円を確認する。
3. **0:35–0:50｜教育へ移す**
   - 教育と文化を15,922億円から16,762億円へ動かす。
   - 配分可能額が0億円へ戻り、年間総予算が96,530億円のままであることを示す。
4. **0:50–1:20｜変更の意味を見る**
   - 公債費を選び直して「詳しく見る」へ進む。
   - 元金返済・利子支払いであること、返済義務が消えるわけではないこと、4つの変更方法を確認する。
5. **1:20–1:35｜事例の限界を見る**
   - 夕張市とプエルトリコの事例を確認する。
   - 東京都の結果予測ではない注意書きを示す。
6. **1:35–1:50｜予算の決まり方を見る**
   - 各局要求、財務局査定、知事査定、予算案、都議会審議、議決・成立の順を確認する。
7. **1:50–2:00｜現実の参加先へつなぐ**
   - 公債費の主な所管である財務局、都民の声、請願・陳情の公式案内を確認する。

## 自動確認

Chromeをデバッグポート9223で起動し、ローカル開発サーバーのURLを指定する。

```sh
npm run audit:demo -- http://localhost:5173
```

11項目を実ブラウザで操作・確認し、120秒以上かかった場合またはいずれかの表示が欠けた場合は失敗する。
