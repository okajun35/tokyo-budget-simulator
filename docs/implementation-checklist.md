## 0. このチェックリストの使い方

- 上から依存順に進める。
- 原則として、チェック項目1つを1コミットまたは1レビュー単位にする。
- 各項目は、直下の「完了条件」を満たしたときだけ完了にする。
- 仕様・レイアウト・公式データが矛盾した場合は、次の優先順位で判断する。

```text
機能要件        docs/tokyo_budget_lab_spec_v0.1.md
PCレイアウト    docs/web-image.png
スマホUX        docs/レイアウト-補足.md
金額・年度      公式資料から作成した構造化データ
```

> `web-image.png` 内の金額は現行コードおよび仕様書と一致しないため、画像はレイアウト参照に限定し、数値の根拠には使用しない。

### 4-A. 年間総予算を変えない再配分へ変更する

各分野を独立して増減させる試算ではなく、限られた年間総予算を分野間で再配分する体験とする。以下はTDDにより振る舞いを確認した。

- [x] 4.11 年間総予算を不変条件として定義する
  - 完了条件：各分野への配分額と未配分額の合計が、常に基準となる年間総予算と一致する。

- [x] 4.12 分野を減額した金額を「配分可能額」へ加える
  - 例：Aを100億円減らすと、配分可能額が100億円になる。
  - 完了条件：減額と配分可能額の増加が同額であり、丸めによる不一致がない。

- [x] 4.13 配分可能額の範囲内で別分野を増額できるようにする
  - 例：配分可能額100億円のとき、Bを最大100億円増やせる。
  - 完了条件：Bの増額分だけ配分可能額が減り、全額をBへ配ると0円へ戻る。

- [x] 4.14 配分可能額を超える増額を防ぐ
  - 完了条件：配分可能額が0円の状態では増額できず、先に別分野を減らす必要があることを画面で説明する。

- [x] 4.15 各分野の70〜130％制限と固定総額を両立させる
  - 完了条件：増額先が上限、減額元が下限に達した場合も年間総予算の不変条件が崩れない。

- [x] 4.16 合計表示を固定総額方式に合わせて変更する
  - 完了条件：「財源不足／余裕」ではなく「配分可能額」または「未配分額」を常時確認でき、年間総予算が変わっていないことが分かる。

- [x] 4.17 リセットで成立予算の配分へ戻す
  - 完了条件：全分野が成立予算額へ戻り、配分可能額が0円になる。

- [x] 4.18 固定総額の再配分をテストで保証する
  - 完了条件：Aの減額、Bへの再配分、配分可能額超過、70〜130％境界、リセットを振る舞い単位で検証する。
