# 東京予算ラボ — ダウンロード版

令和8年度東京都予算を題材にした、予算配分シミュレーターのソースコードです。

## 動作環境

- Node.js 20以上
- npm

## 起動方法

```bash
npm install
npm run dev
```

起動後、ターミナルに表示されるローカルURLをブラウザで開いてください。

## 本番ビルド

```bash
npm run build
```

## 主な編集箇所

- `app/page.tsx`: 画面、予算データ、出典情報、操作ロジック
- `app/globals.css`: レイアウトとデザイン
- `app/layout.tsx`: ページタイトルなどのメタデータ

## 注意事項

- 東京都の公式サービスではない非公式プロトタイプです。
- `.openai/hosting.json` とSitesマニフェストは使用していません。公開先の設定はホスティング方式の決定後に追加します。
- 公開版の初期値は、令和8年度予算概要と東京都オープンデータのCSVを基にしています。
- 再配布・公開時は、各一次資料の利用条件と表示内容を再確認してください。
